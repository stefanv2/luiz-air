# Republic of ECO Website

Starterwebsite voor het fictieve land van Luiz: Republic of ECO.

## Bestanden

- `index.html` - hoofdpagina
- `football.html` - voetbalpagina
- `style.css` - alle styling
- `assets/` - afbeeldingen uit de Republic of ECO wereld

## Lokaal openen

Dubbelklik op `index.html`.

## In GitHub Pages zetten

1. Maak een repository aan, bijvoorbeeld `republic-of-eco`
2. Upload alle bestanden
3. Ga naar Settings > Pages
4. Kies Branch: `main`, folder: `/root`
5. Open de GitHub Pages URL
